# Русская локализация

Интерфейс WPF, заголовки окон, диалоги, табло, сообщения импорта/экспорта, тексты API об ошибках и пользовательская документация переведены на русский язык.

Имена enum, идентификаторы API/JSON и коды в Excel (`Kyu8`, `Male`, `Kata` и т. д.) сохранены без изменений, чтобы не нарушить совместимость данных. В интерфейсе для этих значений отображаются русские подписи. Генерируемый шаблон Excel имеет русские заголовки; импорт читает столбцы по позиции и пропускает первую строку заголовков.

Рекомендуемая быстрая проверка в Windows после распаковки:

```powershell
dotnet restore
dotnet build
dotnet test
```

Если восстановление NuGet не проходит из-за TLS/сертификата Fiddler, сначала исправьте сертификат/перехват HTTPS, а затем повторите команды.
