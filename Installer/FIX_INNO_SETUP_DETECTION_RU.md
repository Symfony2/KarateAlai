# Исправление обнаружения Inno Setup

Сборщик больше не ограничивается несколькими жёстко заданными путями. Он проверяет PATH, записи Inno Setup в реестре Windows, Program Files, пользовательские каталоги и ссылки/пакеты WinGet.

Если автоматический поиск всё равно не нашёл компилятор, передай полный путь параметром `-InnoSetupCompilerPath`.

Проверка пути: `Test-Path 'C:\полный\путь\ISCC.exe'`.
