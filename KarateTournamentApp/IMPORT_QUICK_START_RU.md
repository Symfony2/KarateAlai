# Быстрый старт: импорт и группировка спортсменов

## 1. Создайте Excel-шаблон

1. Откройте боковое меню кнопкой ☰.
2. Нажмите **«Шаблон Excel»**.
3. Заполните лист **«Участники»**, оставив строку заголовков.

В шаблоне есть поля: имя, фамилия, возраст, страна, клуб, пояс, пол, вес (кг) и дисциплины. Для страны, пояса, пола и дисциплин предусмотрены выпадающие списки; страну также можно вписать вручную. Вес необязателен, но нужен для распределения кумитэ по весовым классам. Старые файлы без колонки веса тоже поддерживаются.

## 2. Настройте диапазоны

В панели **«Правила категорий»** справа включите нужные параметры и задайте диапазоны через `;`.

Пример возраста:

`до 5; 6-8; 9-10; 11-13; 14-15; 16; 17; 18; 19+`

Пример веса:

`до 25; 25-30; 31-35; 36-40; 41-45; 46-50; 51-55; 56-60; 61-65; 66-70; 71-80; 81+`

Нажмите **«Применить правила»**. Список категорий перегруппируется. Категории с одним участником не скрываются.

При общей границе (например, `до 25; 25-30`) ровно 25 кг остаётся в первой категории, а вес 25,1 кг уже относится ко второй. Дробный вес округляется вверх до целого кг.

## 3. Импортируйте файл

1. Нажмите **«Импорт из Excel»**.
2. Выберите заполненный файл.
3. Просмотрите количество добавленных и пропущенных строк.
4. Проверьте категории и одиночные группы перед жеребьёвкой.

## 4. Проведите жеребьёвку

У нужной категории нажмите **«Жеребьёвка»**, затем **«Старт»**. Перед изменением диапазонов после начала соревнований приложение предупредит, что сетки и результаты будут сброшены.

Подробный формат Excel см. в [инструкции по импорту](EXCEL_IMPORT_README.md).
